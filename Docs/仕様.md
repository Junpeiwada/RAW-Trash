# RAW-Trash 仕様書

## 概要

カメラで撮影した RAW ファイルと JPG ファイルのペアを管理・整理するデスクトップアプリケーション。  
対応する JPG が存在しない RAW ファイルを `Del/` フォルダに移動し、残りのファイルを RAW/JPG 別フォルダに分類する。

## 対応フォーマット

### RAW フォーマット

| 拡張子 | メーカー |
|--------|----------|
| `.ARW` | Sony |
| `.ORF` | Olympus |
| `.CR3` / `.CR2` | Canon |

大文字・小文字どちらも認識する（例: `.arw` / `.ARW` 両方対応）。

### JPG フォーマット

`.jpg` / `.jpeg` の両拡張子を JPG ファイルとして扱う（大文字・小文字どちらも対応）。

## 機能仕様

### 1. フォルダ選択

- **ドラッグ&ドロップ**: ウィンドウにフォルダをドロップして対象フォルダを指定
- **ダイアログボタン**: 「フォルダを選択」ボタンでシステムの選択ダイアログを開く
- **テキストフィールド**: 絶対パスを直接入力・コピペでも指定可能。D&D / ダイアログ選択時は自動でフィールドに反映される。相対パスや空文字列の場合は実行ボタンを非活性にする

### 2. ファイル整理処理

「実行」ボタンを押すと以下の順で処理を行う。

#### Step 1: サブフォルダ作成

対象フォルダ内に以下の3つのサブフォルダを作成する（既存の場合はスキップ）。

```
<対象フォルダ>/
├── Del/   ← 対応 JPG がない RAW ファイルの移動先
├── RAW/   ← 対応 JPG がある RAW ファイルの移動先
└── JPG/   ← すべての JPG ファイルの移動先
```

#### Step 2: 孤立 RAW の検出・移動

対象フォルダ直下の RAW ファイルをスキャンし、同名の JPG ファイルが存在しないものを `Del/` に移動する。

- スキャン対象: 対象フォルダ直下のファイルのみ。Step 1 で作成した `Del/`, `RAW/`, `JPG/` サブフォルダ自身はスキャン対象外とする
- ペア判定: ファイル名（拡張子なし）が一致する `.jpg` または `.jpeg` ファイルが対象フォルダ直下に存在するか確認
- 例: `DSC_0001.ARW` → `DSC_0001.JPG` / `DSC_0001.jpg` / `DSC_0001.jpeg` のいずれも存在しない場合 → `Del/DSC_0001.ARW` に移動

#### Step 3: ファイル分類

Step 2 で残った対象フォルダ直下のファイルを分類する。`Del/`, `RAW/`, `JPG/` サブフォルダ自身はスキャン対象外とする。

| ファイル種別 | 移動先 |
|-------------|--------|
| RAW ファイル（ARW / ORF / CR3 / CR2） | `RAW/` |
| JPG ファイル（.jpg / .jpeg） | `JPG/` |
| その他のファイル | そのまま（移動しない） |

### 3. 処理結果の表示

処理完了後、以下の情報を画面に表示する。

- 処理したファイルの総数（`Del/` + `RAW/` + `JPG/` に移動したファイルの合計。その他ファイルは含まない）
- `Del/` に移動したファイル数
- `RAW/` に移動したファイル数
- `JPG/` に移動したファイル数

### 4. エラーハンドリング

| エラー条件 | 対応 |
|-----------|------|
| フォルダが選択されていない / パスが絶対パスでない | 実行ボタンを非活性にする |
| 指定フォルダが存在しない | エラーメッセージをダイアログで表示 |
| 移動先に同名ファイルが存在する | 連番サフィックスを付けてリネームして移動する（例: `DSC_0001_1.ARW`）。既に `_1` が存在する場合は `_2` と連番を増やす。リネーム後はRAW/JPGのペア関係は保証しない |
| ファイル移動に失敗 | エラーメッセージをダイアログで表示し、処理を中断する。中断前に移動済みのファイルはロールバックしない |
| 対象ファイルが0件 | 「対象ファイルが見つかりませんでした」と表示 |

## IPC 設計

`ipcRenderer.invoke` / `ipcMain.handle` による request-response 型を採用する。

### Renderer → Main（invoke）

| チャンネル | 引数 | 戻り値 |
|-----------|------|--------|
| `sort:execute` | `folderPath: string` | `Promise<SortResult>`（エラー時は reject） |
| `dialog:openFolder` | なし | `Promise<string \| null>`（キャンセル時は null） |

### 型定義（shared/types.ts 予定）

```typescript
export interface SortResult {
  total: number;   // Del + RAW + JPG に移動したファイルの合計（その他ファイルは含まない）
  deleted: number; // Del/ に移動
  raw: number;     // RAW/ に移動
  jpg: number;     // JPG/ に移動
}
```
