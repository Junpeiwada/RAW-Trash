# RAW-Trash 仕様書

## 概要

カメラで撮影した RAW ファイルと JPG ファイルのペアを管理・整理するデスクトップアプリケーション。  
対応する JPG が存在しない RAW ファイルを `Del/` フォルダに移動し、残りのファイルを RAW/JPG 別フォルダに分類する。

## 技術スタック

| 項目 | 内容 |
|------|------|
| フレームワーク | Electron |
| 言語 | TypeScript |
| UI | React |
| バンドラ | Webpack |
| 対象プラットフォーム | macOS |

## 対応 RAW フォーマット

| 拡張子 | メーカー |
|--------|----------|
| `.ARW` | Sony |
| `.ORF` | Olympus |
| `.CR3` / `.CR2` | Canon |

大文字・小文字どちらも認識する（例: `.arw` / `.ARW` 両方対応）。

## 機能仕様

### 1. フォルダ選択

- **ドラッグ&ドロップ**: ウィンドウにフォルダをドロップして対象フォルダを指定
- **ダイアログボタン**: 「フォルダを選択」ボタンでシステムの選択ダイアログを開く
- 選択中のフォルダパスは画面に表示する

### 2. ファイル整理処理

「実行」ボタンを押すと以下の順で処理を行う。

#### Step 1: サブフォルダ作成

対象フォルダ内に以下の3つのサブフォルダを作成する（既存の場合はスキップ）。

```
<対象フォルダ>/
├── Del/   ← 対応 JPG がない RAW ファイルの移動先
├── RAW/   ← 対応 JPG がある RAW ファイルの移動先
└── JPG/   ← すべての JPG ファイルの移動先
```

#### Step 2: 孤立 RAW の検出・移動

対象フォルダ直下の RAW ファイルをスキャンし、同名の JPG ファイルが存在しないものを `Del/` に移動する。

- ペア判定: ファイル名（拡張子なし）が一致する JPG ファイルが対象フォルダ直下に存在するか確認
- 例: `DSC_0001.ARW` → `DSC_0001.JPG` が存在しない場合 → `Del/DSC_0001.ARW` に移動

#### Step 3: ファイル分類

Step 2 で残った対象フォルダ直下のファイルを分類する。

| ファイル種別 | 移動先 |
|-------------|--------|
| RAW ファイル（ARW / ORF / CR3 / CR2） | `RAW/` |
| JPG ファイル | `JPG/` |
| その他のファイル | そのまま（移動しない） |

### 3. 処理結果の表示

処理完了後、以下の情報を画面に表示する。

- 処理したファイルの総数
- `Del/` に移動したファイル数
- `RAW/` に移動したファイル数
- `JPG/` に移動したファイル数

### 4. エラーハンドリング

| エラー条件 | 対応 |
|-----------|------|
| フォルダが選択されていない | 実行ボタンを非活性にする |
| 指定フォルダが存在しない | エラーメッセージをダイアログで表示 |
| ファイル移動に失敗 | エラーメッセージをダイアログで表示し、処理を中断 |
| 対象ファイルが0件 | 「対象ファイルが見つかりませんでした」と表示 |

## IPC 設計

### Main → Renderer

| チャンネル | 内容 |
|-----------|------|
| `sort:result` | 処理結果（移動件数）を返す |
| `sort:error` | エラー内容を返す |

### Renderer → Main

| チャンネル | 内容 |
|-----------|------|
| `sort:execute` | 対象フォルダパスを渡して処理を依頼 |
| `dialog:openFolder` | フォルダ選択ダイアログを開く依頼 |

### 型定義（shared/types.ts 予定）

```typescript
export interface SortResult {
  total: number;
  deleted: number;  // Del/ に移動
  raw: number;      // RAW/ に移動
  jpg: number;      // JPG/ に移動
}
```
